# Governance baseline

AegisWeft starts with no model or tool permissions. Future connectors must declare operations, scopes, data handling, and risk level. Runtime permissions—not prompt wording—enforce access.

Require human approval for production deployment, destructive data changes, external communications, and policy exceptions. Keep a trace of provider/model, catalog versions, tool calls, approvals, outputs, and verification evidence. Route confidential repositories only through approved providers. Treat repository text, issue content, and tool output as untrusted input.
